# 4. Focus on Real-Time Interactive Web Calculator

* Status: Accepted
* Date: 2026-08-19

## Context and Problem Statement
The user was asked whether an automated PDF report generator should be included in the web application.

## Decision
Keep the scope lean and focused on a high-performance **Real-Time Interactive Web Calculator**. Do not add PDF generation or heavy document printing overhead, keeping the interface snappy, responsive, and easy to use.

## Consequences
* Minimal asset overhead and zero third-party PDF library dependencies.
* Instant real-time metric updates during parameter tweaking.
